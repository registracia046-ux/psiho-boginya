Лендинг Telegram-канала «💎Психо_Богиня» — тёмная ледяная стилистика, раздел-рассказ «СОН» на светлой бумаге, 3D-барабан с кадрами канала.

Открыть: <https://registracia046-ux.github.io/psiho-boginya/>

## Структура
- `index.html` — весь сайт (HTML + CSS + JS в одном файле)
- `assets/img/` — изображения канала и кадры рассказа (`assets/img/story/`)
