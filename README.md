# ПСИХО_БОГИНЯ

Многостраничный лендинг Telegram-канала «💎Психо_Богиня» — тёмная ледяная стилистика, раздел-рассказ «СОН» на светлой бумаге, 3D-барабан с кадрами из канала, раздел «Из переписки».

**Главная:** https://registracia046-ux.github.io/psiho-boginya/

## Структура
| Файл | Раздел |
|---|---|
| `index.html` | Главная: первый экран + «Все разделы» |
| `paths.html` | Два пути |
| `clinic.html` | Клиника (протокол приёма) |
| `marionettes.html` | Марионетки |
| `son.html` | Сон (рассказ) |
| `dials.html` | Из переписки |
| `voice.html` | Мой голос |
| `bills.html` | Счета |
| `gallery.html` | Галерея (3D-барабан) |
| `admit.html` | Вход |
| `onepage.html` | **Всё одной страницей** — запасной вариант |

Общее для всех страниц: гейт 18+, шапка с навигацией, мобильная шторка, подвал, липкая мобильная кнопка, лайтбокс, единый CSS и JS.

## Ресурсы
- `assets/img/` — изображения канала
- `assets/img/story/` — кадры рассказа «СОН»
- `assets/img/dialogs/` — скрины переписок (раздел «Из переписки»)

Источник для пересборки лежит отдельно: `site_src/index.html` → `python3 build_pages.py`.
