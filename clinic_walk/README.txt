ХОДИЛКА ПО КЛИНИКЕ — встроена в страницу clinic.html (и onepage.html).
Всё вынесено с префиксом cw-, чтобы не задевать остальной сайт.

ФАЙЛЫ
  block.html  — разметка блока. Вставлять в раздел «Клиника» сразу после
                 .sec-head (там, где </div> закрывает sec-head).
  style.css   — стили. Вставлять перед </style> во ВСЕ страницы
                 (каждая страница самодостаточна: свой style и свой script).
  script.js   — логика. Вставлять отдельным <script> перед </body> во все страницы.

АССЕТЫ
  assets/img/clinic/
    corridor_plain.jpg  — коридор (койки слева, шкафы и стулья справа)
    ward_one.jpg        — палата №1 (2 койки, 1 шкаф, 1 стул)
    ward_two.jpg        — палата №2 (4 койки, 2 шкафа, 2 стула)
    clinic_office.jpg   — кабинет (две двери, консоль с подносом)
    obj_*.png           — предметы (СКОПОЛАМИН, ДИМЕДРОЛ, шприц, стакан, ремни, тетрадь)

РАСШИРЕНИЕ
  В script.js есть реестр CW_ROOMS: { имя, img, focus, items[], doors[], exits[] }.
  Новая палата = одна запись + картинка 21:9. Файл кадрируется до центральной
  полосы 62% высоты — иначе картинка уже экрана и ездить не по чему.

ПЕРЕГЕНЕРИРОВАТЬ КАРТИНКИ
  node-скрипта нет, картинки сгенерированы mcode-tools (connector__matrix__generate_image),
  промпты и node_id — в /workspace/clinic_demo (make_assets.py).
